# Airoco Notify System

教室の環境データ（CO2、温度、湿度）を監視・通知し、可視化するプラットフォームです。
センサーから取得したデータを分析し、Slackへの通知やWeb上でのスコア表示を行うことで、学習環境の改善を促進します。

## プロダクト概要

「快適な学習環境」を維持するためのモニタリングアプリケーションです。
Airocoセンサーから取得したデータを基に、教室ごとの環境スコア（CO2濃度、温度、湿度）を算出。Slackでの自動通知機能により、換気や空調調整のタイミングを周知できるほか、Webアプリ上で過去のデータを星評価で確認することができます。

## 機能

1.  **環境データ取得**:
    *   Airoco APIを使用したセンサーデータの定期取得
    *   対象教室: R3-301, R3-401, R3-403
2.  **データ集計・分析**:
    *   時限ごと（1限〜6限）のデータ抽出
    *   平均値の算出および環境スコア（3段階の星評価）の計算
3.  **通知機能**:
    *   Slackチャンネル（#r3-301, #r3-401, #r3-403等）への自動通知
    *   環境スコアに基づいたメッセージ送信
4.  **Web可視化（Frontend）**:
    *   日付ごとの環境スコア表示
    *   教室別・時限別の詳細データ確認
    *   CO2、温度、湿度の数値を星評価で直感的に表示
5.  **データ保存**:
    *   算出されたスコアデータのデータベース保存

## 環境変数

本プロジェクトの動作には、以下の環境変数が必要です。`.env`ファイル等に設定してください。

### Backend
*   `AIROCO_API_BASE_URL`: Airoco APIのベースURL
*   `AIROCO_ID`: センサーID
*   `AIROCO_API_KEY`: APIサブスクリプションキー
*   `SLACK_API_TOKEN`: Slack Bot Token
*   `SUPABASE_DB_HOST`: Supabase データベースホスト
*   `SUPABASE_DB_NAME`: データベース名（通常 `postgres`）
*   `SUPABASE_DB_USER`: データベースユーザー
*   `SUPABASE_DB_PASSWORD`: データベースパスワード
*   `SUPABASE_DB_PORT`: データベースポート（通常 `5432`）

### Frontend
*   `VITE_SUPABASE_URL`: Supabase URL
*   `VITE_SUPABASE_ANON_KEY`: Supabase Anon Key

## Supabaseセットアップ

本プロジェクトでは、データの保存先としてSupabase（PostgreSQL）を使用しています。
プロジェクトを作成後、SQLエディタで以下のクエリを実行してテーブルを作成してください。

```sql
-- テーブルの作成
create table classroom_scores (
  id bigint generated by default as identity primary key,
  classroom text not null,
  date date not null,
  day_of_week text not null,
  period integer not null,
  co2_score integer not null,
  temperature_score integer not null,
  humidity_score integer not null,
  co2_value float not null,
  temperature_value float not null,
  humidity_value float not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- アップサート（重複更新）用のユニーク制約を追加
alter table classroom_scores
add constraint classroom_scores_unique_entry unique (classroom, date, period);

-- RLS（Row Level Security）の有効化
alter table classroom_scores enable row level security;

-- 読み取り権限の付与（Frontendからのアクセス用）
create policy "Enable read access for all users"
on "public"."classroom_scores"
as permissive
for select
to public
using (true);
```

## セットアップ手順

以下の手順に従って、ローカル開発環境を構築してください。

### 1. 前提条件

*   **Python**: 3.9以上
*   **Node.js**: 20.x以上 (npm含む)
*   **Supabase アカウント**: データベースとプロジェクトの作成が必要です。

### 2. 環境変数の設定

プロジェクトのルートディレクトリおよび `frontend` ディレクトリに必要な設定を行います。

1.  ルートディレクトリに `.env` ファイルを作成し、以下の情報を記入します。
    ```env
    # Airoco API
    AIROCO_API_BASE_URL=https://...
    AIROCO_ID=your_sensor_id
    AIROCO_API_KEY=your_api_key

    # Slack
    SLACK_API_TOKEN=xoxb-...

    # Supabase (Database Connection)
    SUPABASE_DB_HOST=aws-0-...
    SUPABASE_DB_NAME=postgres
    SUPABASE_DB_USER=postgres
    SUPABASE_DB_PASSWORD=your_password
    SUPABASE_DB_PORT=5432
    ```

2.  `frontend/.env.local` （または `.env`）ファイルを作成し、以下の情報を記入します。
    ```env
    VITE_SUPABASE_URL=https://your-project.supabase.co
    VITE_SUPABASE_ANON_KEY=your_anon_key
    ```

### 3. Backend (Python) のセットアップ

1.  **依存ライブラリのインストール**
    ```bash
    # (推奨) 仮想環境の作成
    python -m venv venv
    source venv/bin/activate  # Windowsの場合は venv\Scripts\activate

    # ライブラリのインストール
    pip install -r backend/installed/requirements.txt
    ```

2.  **実行確認**
    ```bash
    python backend/main.py
    ```
    ※ このスクリプトは指定された教室のデータを取得し、Slackへの通知とデータベースへの保存を一度に行います。定期実行する場合は、cronやGitHub Actions等で設定してください。

### 4. Frontend (React) のセットアップ

1.  **依存ライブラリのインストール**
    ```bash
    cd frontend
    npm install
    ```

2.  **開発サーバーの起動**
    ```bash
    npm run dev
    ```
    起動後、ターミナルに表示されるURL（例: `http://localhost:5173`）をブラウザで開きます。

## 自動実行 (GitHub Actions)

本プロジェクトは、GitHub Actions を使用してバックエンドの定期実行とフロントエンドの自動デプロイを行うように構成されています。

*   **Backend**: 月曜〜金曜の 19:50 (JST) に `main.py` が自動実行され、Slack通知とDB更新が行われます。
*   **Frontend**: `main` ブランチへのプッシュ時に自動ビルドされ、GitHub Pages にデプロイされます。

GitHub リポジトリの `Settings > Secrets and variables > Actions` に、`環境変数` セクションに記載した全てのシークレットを登録してください。
